Photography layout — portfolio-aligned alternatives

Each variation renders inside a faithful mock of the live portfolio page (same background, top bar, Mackinac title, mono caption). The grid is what changes — quietly enough to belong on the site, but different enough that /photography doesn't feel like a copy of /work.

Option A

Masonry — mixed orientation

Differs from /work via varied heights & orientations, not just content.
Three CSS columns; portraits, landscapes and squares flow organically. The work page's uniform grid feels engineered — masonry feels personal, like a Polaroid wall.

Option I

Dense gallery wall — varied bento

Like /work but with true size variation: some photos span 4 cols, some 2; portrait, landscape, panoramic, square all coexist.
